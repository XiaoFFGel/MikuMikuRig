# MikuMikuRig

**傻瓜式 MMD K帧插件** —— 不用懂绑定，也能在 Blender 里给 MMD 模型 K 帧做动画。

## 它能做什么

- **一键生成控制器**：给 MMD 骨骼生成 Rigify 控制器，用 IK 直接摆姿势
- **动作导入导出**：导入 VMD / FBX（含 Mixamo）动作，也能导出回 VMD
- **MMD 物理**：增强版刚体物理，可烘焙到骨骼
- **表演面板**：批量管理形态键，K 口型表情更方便
- **骨骼映射工具**：把任意骨架的动作搬到你的模型上

## 安装

1. 先安装前置插件 **MMD Tools**（导入 MMD 模型必须用）。
2. 到 [Releases](https://github.com/XiaoFFGel/MikuMikuRig/releases) 按你的 Blender 版本下载 zip：

| 你的 Blender 版本 | 下载 |
| --- | --- |
| 3.6 LTS | MikuMikuRig 3.6-x |
| 4.5 LTS | MikuMikuRig 4.5-x |
| 5.2 | MikuMikuRig 5.2.x |

3. `编辑 → 偏好设置 → 插件 → 安装`，选 zip，勾选启用。

启用后按 N 键，3D 视图右侧会出现 **MMR** 标签页。
